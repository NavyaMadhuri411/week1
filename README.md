# Experiment 1: Prompt Engineering Lab Setup

## Aim
To establish a working environment for prompt engineering and verify communication with a Large Language Model using the Gemini API.

## Technologies Used
- Python
- Google Colab
- Google Gemini API
- Google Gen AI SDK

## Problem Statement
Load a Gemini API key securely, send a predefined prompt to the Gemini model, display the generated response, and handle API errors.

## Prompt
"What is prompt engineering? Answer in one sentence."

## Execution
1. Open the Jupyter notebook in Google Colab.
2. Configure your Gemini API key securely.
3. Install the required library using `pip install google-genai`.
4. Run the code cells.
5. Verify the generated response.

## Result
The Gemini API connection was established successfully, and the model generated a response to the predefined prompt.
